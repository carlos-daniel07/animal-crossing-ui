# 🍃 Animal Crossing UI - Bootstrap Landing Page

Maquetación temática de interfaz web que demuestra la integración del framework Bootstrap con estilos CSS personalizados. El proyecto se centra en utilizar un framework estructural estándar y modificar sus variables visuales para lograr una identidad de marca específica (pixel-perfect) sin comprometer la responsividad.

🔗 **[Ver Maquetación en Vivo](https://animal-crossing-ui.netlify.app/)**

## 🚀 Arquitectura y Características

* **Estructura Responsiva (Grid System):** Uso avanzado de la grilla de Bootstrap (`row-cols-md`, clases de display `d-none d-md-block`) para garantizar adaptabilidad nativa en dispositivos móviles, tablets y escritorio.
* **Componentes UI Nativos:** Implementación de Carrusel interactivo, Navbar colapsable y sistema de Tarjetas (Cards) aprovechando el JavaScript preconstruido del framework.
* **CSS Overrides y Estilización Avanzada:** Sobrescritura de estilos mediante una hoja de estilos propia (`main.css`) para aplicar gradientes lineales repetitivos (`repeating-linear-gradient`), manipulación del modelo de caja y fondos compuestos con múltiples capas.
* **Manejo de Profundidad (Z-Index):** Posicionamiento superpuesto de componentes (como el ribbon decorativo y elementos desbordados) para crear un efecto visual de 2.5D.

## 🛠️ Tecnologías Utilizadas

* **HTML5 Semántico**
* **CSS3 (Custom Overrides)**
* **Bootstrap 5 (Estructura y Componentes)**

## 🧠 Objetivo del Proyecto
El enfoque principal fue dominar la personalización sobre un framework estricto. En lugar de limitarse a las clases utilitarias genéricas de Bootstrap, se integró una capa de CSS puro para lograr texturas complejas, sombras y posicionamientos absolutos, demostrando flexibilidad y control total sobre el motor de renderizado del navegador.
